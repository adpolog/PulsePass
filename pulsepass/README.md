# PulsePass 
### Integrantes: Andry Polo Granados, Daniel Ramos Heras

Aplicación backend desarrollada en Spring Boot para la gestión integral de eventos y venta de boletería, aplicando principios de arquitectura limpia y persistencia robusta.

##  Stack Tecnológico
* **Java 21**
* **Spring Boot 4.1.1** (Spring Data JPA)
* **PostgreSQL**
* **Flyway** (Control de migraciones de base de datos)
* **Testcontainers** (Pruebas de integración atómicas con contenedores reales)
* **Lombok** (Optimización de código repetitivo)
